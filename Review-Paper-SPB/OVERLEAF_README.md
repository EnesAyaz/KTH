# Overleaf source package

Upload overleaf_source.zip as a new Overleaf project. Set main.tex as the
main document and use pdfLaTeX. The supplied IEEE OJPEL class, logo,
bibliography style, abbreviation files, sections, and figure assets are included.

All 16 figures are embedded from Figures/Exported/fig01.pdf through fig16.pdf.
The same folder has 300-dpi PNG previews and SVG copies. Captions are in
Sections/*.tex. Original drawing code and analytical data remain in Figures/.
See Figures/Exported/README.md for the export/rebuild procedure.

A compact 2-pt gap above figure captions is set in main.tex. Exported PDFs
have tight content bounds; manual negative vspace is unnecessary.

Use the original TIFF/PNG model images as supplied when regenerating the
case-study figure. Numerical case-study results remain analytical estimates.
