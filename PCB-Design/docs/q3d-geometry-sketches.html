EPC2361 DPT cell: Q3D model geometry (simulation/q3d/q3d_dpt_cell.py)

Nets: DCP (DC+)AC SQL (QL source / shunt in)DCN (DC−) pads = terminals

Q3D results (no shunt, h_diel = 0.1 mm, 100 MHz), effective loop at the QL switch, copper / with MLCC ESL: PL_A 0.310 / 0.390 nH, PL_B 0.303 / 0.383 nH, PL_C (h_23 0.1 mm) 0.288 / 0.333 nH, PL_C (h_23 1.2 mm) 0.306 / 0.372 nH. The EPC2361 package is not included. EPC's "optimal power loop" (WP010, 4 mil) is 0.35–0.4 nH including parts, so these designs are close to the EPC optimum.
