# Basic current-sharing model: two parallel EPC2361

`Sharing_2xEPC2361.asc` is a small, fully wired LTspice schematic. It is a low-side double-pulse test of two parallel EPC2361s (QL1, QL2) with one EPC2361 high side (QH, held off). Each branch has its own lumped parasitics, so you can see what each one does to current sharing. It is generated by `python scripts/make_sharing_asc.py`; edit the `.param` lines in the schematic directly.

**Open:** double-click `Open-Sharing.cmd` (or open the `.asc` in LTspice) and press Run. Six cases run in about 2 min. Plot `I(LD1)` and `I(LD2)` (drain currents), `V(D1,S1)`, `V(G1,S1)`, `V(G2,S2)` and `V(DH,SW)`. To run one case only, replace `.step param CASE list 0 1 2 3 4 5` with `.param CASE=2` (for example).

## Circuit and knobs

```
Vbus --Lloop(+RLOOP)--+-- QH (off) --+-- SW --+-- LD1 -- QL1 -- LS1 -- GND
                      +--- Lload ----+        +-- LD2 -- QL2 -- LS2 -- GND
Vdrv -- VTHk -- RGk -- LGk -- gate k ;  driver return: Kelvin (RKk to die source) or power ground (Rp)
```

| Parameter | Meaning | Baseline |
| --- | --- | --- |
| LLOOP, RLOOP | shared part of the power loop (bus caps, QH) | 0.1 nH, 8 mΩ |
| LD1, LD2 | drain-side power-loop inductance per branch | 0.15 nH |
| LS1, LS2 | source inductance per branch (in the power loop; also in the gate loop if KELVIN = 0) | 0.05 nH |
| LG1, LG2 | gate-loop inductance per branch | 2 nH (Q3D, 8 mm stacked pair) |
| RG1, RG2 | gate resistance per branch (driver output impedance included) | 2 Ω |
| KELVIN | 1: driver returns at each die source through RKS = 0.1 Ω. 0: driver returns at power ground, so LS becomes common-source inductance | 1 |
| DVTH1, DVTH2 | extra gate voltage needed by a branch (emulates a higher threshold) | 0 V |
| VBUS, IPK, LLOAD | 75 V, 120 A, 5 µH (first pulse 8 µs) | |

## The six cases (one change each) and results

| CASE | Change | Peak ID turn-on QL1 / QL2 | I_diff | Eon QL1 / QL2 | Eoff QL1 / QL2 | QH VDS peak |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | baseline, symmetric, Kelvin | 124 / 124 A | 0 % | 9.3 / 9.3 µJ | 7.5 / 7.5 µJ | 106 V |
| 1 | power loop: LD2 +0.3 nH | 126 / 122 A | 2 % | 10.5 / 6.7 µJ | 7.4 / 7.5 µJ | 112 V |
| 2 | gate loop: LG2 2 → 8 nH | 130 / 88 A | 19 % | 19.2 / 4.9 µJ | 6.7 / 7.4 µJ | 95 V |
| 3 | no Kelvin (LS = 0.05 nH common-source L, symmetric) | 94 / 94 A | 0 % | 13.7 / 13.7 µJ | 8.0 / 8.0 µJ | 85 V |
| 4 | no Kelvin + LS2 +0.2 nH | 144 / 79 A | 29 % | 28.3 / 10.2 µJ | 7.7 / 18.0 µJ | 95 V |
| 5 | Vth2 +0.3 V | 127 / 110 A | 7 % | 13.6 / 7.1 µJ | 10.2 / 5.3 µJ | 100 V |

I_diff = (I1 − I2)/(I1 + I2) at the turn-on peak, as in EPC AN020. Static sharing at the end of the 8 µs pulse is 59–60 A per device in every case, because it is set by RDS(on), not by these parasitics.

What it shows:

* **Common-source inductance imbalance is the worst case** (case 4: 29 %, and 2.8× Eon on QL1). With a Kelvin return, LS no longer acts on the gate. Kelvin returns are therefore the first rule.
* **Symmetric common-source inductance does not unbalance, it slows** (case 3: Eon +47 %, overshoot down from 106 to 85 V). That is the negative feedback AN020 describes.
* **Gate-loop imbalance is the next biggest** (case 2: 19 %, Eon 4×). This is why the star gate routing matters on our board.
* **Power-loop (drain) imbalance** mostly shifts switching energy (Eon 10.5 vs 6.7 µJ) and excites a slow oscillation between the two branches. The peak current barely changes.
* **A 0.3 V threshold spread** gives 7 % at turn-on but a 2:1 split of turn-off energy: the lower-threshold device turns off last and briefly carries 80 A. The paralleling paper reports the same mechanism; it can only be reduced by device selection or matching.

The baseline QH peak (106 V) is higher than the full DPT model (86 V, `../dpt/`), because this model has an ideal driver edge, one high-side FET and no MLCC damping. Use this model to compare cases, and the DPT model for absolute overshoot.
