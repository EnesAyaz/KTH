# Decisions

| id | date | decision | reason |
|---|---|---|---|
| D01 | 2026-10-29 | Compare three machines: induction machine (IM), PMSM, and wound-rotor/wound-field synchronous machine (WRSM). | Enes: WRSM is a rising traction trend; pole changing is possible by reversing the excitation direction of rotor coil groups, and it field-weakens by reducing I_f instead of injecting -I_d. IM changes poles on the stator side alone (cage adapts). PMSM rotor poles are fixed: it is the no-pole-change baseline. |
| D02 | 2026-10-29 | Reference vehicle: 40 t long-haul truck, **300 kW**, 1200 V DC link — matches the SPB reference system (2 x 150 kW blocks per leg). Long-haul drive cycle (file pending). | Enes, 2026-10-29: use 300 kW. T03 (350 kW) stays as the run the simulator validates; all new results at 300 kW. |
| D03 | 2026-10-29 | Add a **hybrid-excited synchronous machine** (PM + field winding, Bianchi/Contò type) as a fourth candidate. | Enes: hybrid motor can be a candidate. PM supplies base flux (efficiency, no PF penalty), the field winding reverses selected poles; possibly the best fit for electronic pole changing. |
| D04 | 2026-10-29 | Drive cycles: **VECTO Long Haul** (primary, group 5 tractor-semitrailer, 40 t) and **VECTO Regional Delivery** (secondary: more low-speed/grade work, where low-speed torque per ampere matters); Urban Delivery as a sensitivity case. Data in `data/vecto/`. | Enes: use VECTO for long-haul. EU certification cycles, distance-based with road grade, so results are comparable with the EU CO2 framework. |
| D05 | 2026-10-29 | Number of SPB modules **N is a design variable** (2, 3, 4, 5, ... ), not fixed at 16. N = 16 (75 V class) stays the reference case. | Enes: 16 is the project target, not a must. N sets module voltage (1200/N), device class, and which pole counts/patterns the coil groups can form. |
| D06 | 2026-10-29 | Machine **phase number m is a design variable** (3, 5, 6, 7, 9; per module or across modules), co-designed with N and the slot count. Work mode switches to the **gap loop** (board/gap_loop.md, board/hypotheses.md) with a new gap-critic agent. | Enes: SPB already has multiple inverters, so co-optimise N, m and pole changing; use the agent loop to find the research gap. |
