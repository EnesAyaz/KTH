# Baloch2019distributed

**A Distributed Winding Wound Field Pole-Changing Vernier Machine for Variable Speed Application** (2019), IEEE Transactions on Magnetics. DOI: https://doi.org/10.1109/tmag.2019.2900470

Access: abstract record read (OpenAlex/Crossref); full text not read.

- **Claim:** Wound-field rotor with two field-winding sets; reversing the current in one set changes the pole number, giving vernier mode below base speed and WFSM mode above it.
- **Method:** 2D FEA of both modes at base speed and over variable-speed operation.
- **Machine / inverter:** Distributed-winding wound-field pole-changing vernier machine.
- **Power / voltage / speed numbers:** FEA only; no ratings in abstract.
- **Relevance to SPB:** Only precedent found for pole changing by reversing rotor coil-group excitation, i.e. the D01 WRSM mechanism.
- **Limitations:** FEA only; no hardware or traction rating; vernier machine, not a plain WRSM.
