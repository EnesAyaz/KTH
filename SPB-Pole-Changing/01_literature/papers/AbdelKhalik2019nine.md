# AbdelKhalik2019nine

**Nine‐phase six‐terminal pole‐amplitude modulated induction motor for electric vehicle applications** (2019), IET Electric Power Applications. DOI: https://doi.org/10.1049/iet-epa.2018.5796

Access: abstract record read (OpenAlex/Crossref); full text not read.

- **Claim:** Nine-phase six-terminal pole-amplitude-modulated IM with fractional-slot concentrated winding keeps equal magnetising current for both pole counts (2:1 ratio).
- **Method:** Simulation and experiment; VSD-based controller.
- **Machine / inverter:** Nine-phase IM, six terminals.
- **Power / voltage / speed numbers:** Constant-power operation over more than 4 pu speed range.
- **Relevance to SPB:** Demonstrates electronic pole changing giving CPSR above 4, the truck-relevant range.
- **Limitations:** Lab machine; shared terminals so not one isolated neutral per module.
