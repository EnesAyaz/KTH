# Krupp2015rotary

**Rotary Transformer Design for Brushless Electrically Excited Synchronous Machines** (2015), 2015 IEEE Vehicle Power and Propulsion Conference (VPPC). DOI: https://doi.org/10.1109/vppc.2015.7353009

Access: abstract record read (OpenAlex/Crossref); full text not read.

- **Claim:** Design and loss model of a rotary transformer replacing slip rings in an automotive EESM.
- **Method:** Analytical loss model, scaling rules, FEM, measurements.
- **Machine / inverter:** Brushless EESM, rotary transformer.
- **Power / voltage / speed numbers:** None in abstract.
- **Relevance to SPB:** Defines the path through which pole-reversing rotor excitation would have to be supplied.
- **Limitations:** Single field circuit; no polarity reversal.
