# Olson2024enabling

**Enabling Variable Phase-Pole Drives With the Harmonic Plane Decomposition** (2024), IEEE Access. DOI: https://doi.org/10.1109/access.2024.3375752

Access: abstract record read.

- **Claim:** HPD decomposes all pole-pair fields into a fixed number of orthogonal subspaces with invariant parameters, enabling on-the-fly pole changes; configurations with more than one slot/pole/phase and fractional phase number demonstrated.
- **Method:** Theory, relation to VSD via complex winding factor, FOC pole-transition experiment.
- **Machine / inverter:** Variable phase-pole machine.
- **Power / voltage / speed numbers:** None in abstract.
- **Relevance to SPB:** Core model for any SPB pole-changing control; works for arbitrary coil-group counts.
- **Limitations:** Abstract only.
