# Raj2022design

**Design of a Variable Phase-Pole Induction Machine for Electric Vehicle Applications** (2022), 2022 International Conference on Electrical Machines (ICEM). DOI: https://doi.org/10.1109/icem51905.2022.9910688

Access: abstract record read.

- **Claim:** Variable phase-pole IM with distributed windings switchable between 3-phase/6-pole and 9-phase/2-pole for EVs, smaller than a fixed-configuration IM for the same torque-speed coverage.
- **Method:** Design and control model using Harmonic Plane Decomposition.
- **Machine / inverter:** Variable phase-pole IM (Peretti, KTH).
- **Power / voltage / speed numbers:** 3-phase/6-pole <-> 9-phase/2-pole.
- **Relevance to SPB:** KTH precedent for electronic pole change by phase-count change, which is what SPB isolated coil groups allow.
- **Limitations:** Abstract only; no drive-cycle.
