# Raj2022design

**Design of a Variable Phase-Pole Induction Machine for Electric Vehicle Applications** (2022), 2022 International Conference on Electrical Machines (ICEM). DOI: https://doi.org/10.1109/icem51905.2022.9910688

Access: abstract + full text read (IEEE PDF supplied by Enes).

- **Claim:** Variable phase-pole IM with distributed windings switchable between 3-phase/6-pole and 9-phase/2-pole for EVs, smaller than a fixed-configuration IM for the same torque-speed coverage.
- **Method:** Design and control model using Harmonic Plane Decomposition.
- **Machine / inverter:** Variable phase-pole IM (Peretti, KTH).
- **Power / voltage / speed numbers:** 3-phase/6-pole <-> 9-phase/2-pole.
- **Full-text addition (corrects abstract-level and secondary numbers):** Variable phase-pole IM: 690 V line-to-line, 6 poles, 37 kW, 361 N m, 50 Hz, 979 rpm, 71 A; 36 stator slots, 28 rotor bars, stack 400 mm, rotor radius 100 mm, airgap 0.6 mm; configurations 3-phase/6-pole and 9-phase/2-pole; load torque-speed from a scaled EV profile up to ~5500 rpm, about 400 N m at low speed; fixed-pole reference IM 4-pole 56 kW 360 N m 1482 rpm. The VPPIM needs 37 kW against 56 kW for the fixed-pole reference to cover the same torque-speed map (smaller machine).
- **Relevance to SPB:** KTH precedent for electronic pole change by phase-count change, which is what SPB isolated coil groups allow.
- **Limitations:** Full text now read (see addition). Prototype or FEA scale; no truck-rating machine.
- **SPB note (from full text):** Quantifies how pole changing reduces the required rated power by about one third for the same torque-speed map.
