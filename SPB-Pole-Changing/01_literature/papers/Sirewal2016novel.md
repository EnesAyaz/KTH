# Sirewal2016novel

DOI: https://doi.org/10.1109/tmag.2015.2512281

Access: abstract record read (OpenAlex/Crossref); full text not read.

- **Claim:** Zero-sequence third-harmonic field excitation: thyristor switches across each phase create a spatial third-harmonic current; a 12-pole rotor harmonic winding (stator and field 4-pole) feeds the field winding via rotating rectifier.
- **Method:** 2D FEA.
- **Machine / inverter:** Single inverter with thyristor switches.
- **Power / voltage / speed numbers:** none in abstract.
- **Relevance to SPB:** Zero-sequence route that an isolated-neutral SPB module cannot use; the contrast defines the SPB-specific freedom (any order not divisible by 3).
- **Limitations:** abstract only; small machines, FEA mostly; unipolar field current.
