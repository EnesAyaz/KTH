# Wu2024open

**Open-Phase Fault-Tolerant Pole Transition Control of an Asynchronous Variable-Pole Machine Using Harmonic Plane Decomposition** (2024), IEEE Journal of Emerging and Selected Topics in Power Electronics. DOI: https://doi.org/10.1109/jestpe.2024.3396722

Access: abstract record read.

- **Claim:** Post-fault control for a variable-pole machine with an open-phase fault, operating during pole changing.
- **Method:** HPD post-fault strategy; experiments.
- **Machine / inverter:** 18-phase variable-pole IM prototype.
- **Power / voltage / speed numbers:** 18 phases.
- **Relevance to SPB:** Fault tolerance of many-coil-group pole changing, which SPB (16 isolated modules) would share.
- **Limitations:** Lab scale.
