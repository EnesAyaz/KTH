# Libbos2020loss

**Loss Minimization and Maximum Torque-Per-Ampere Operation for Variable-Pole Induction Machines** (2020), IEEE Transactions on Transportation Electrification. DOI: https://doi.org/10.1109/tte.2020.2997692

Access: abstract record read (OpenAlex/Crossref); full text not read (IEEE Xplore returns an anti-bot page, HTTP 418, to curl even through the VPN; stopped for that host).

- **Claim:** Pole selection by torque and speed (not speed alone) minimises current and machine loss in a variable-pole IM; average loss reduced by 1/3 and torque per ampere doubled at partial load.
- **Method:** Experimental 36-slot toroidally wound IM on an 18-leg inverter.
- **Machine / inverter:** 36-slot toroidal IM, 18 legs.
- **Power / voltage / speed numbers:** Loss -1/3 at partial loading; torque per ampere x2.
- **Relevance to SPB:** Evidence that pole count is an efficiency lever at partial load, not only a speed-range lever (the logic the SPB truck cycle needs).
- **Limitations:** Lab scale.
