# Ran2024drive

**Drive-cycle system efficiency evaluation of electrically excited synchronous machine with dynamic motor drive** (2024), IET Conference Proceedings. DOI: https://doi.org/10.1049/icp.2024.2204

Access: abstract record read (OpenAlex/Crossref); full text not read.

- **Claim:** Drive-cycle system-efficiency method (FEA + analytical) including power electronics, control, machine and cycle, for an EESM vs a commercial IPM.
- **Method:** Ansys FEA plus Matlab analytical model.
- **Machine / inverter:** EESM with the IPM stator and winding.
- **Power / voltage / speed numbers:** Optimised EESM has higher torque, power and system efficiency than the IPM.
- **Relevance to SPB:** Template for the drive-cycle system-efficiency evaluation the SPB study needs.
- **Limitations:** Abstract only.
