# Zhao1995space

**Space vector PWM control of dual three-phase induction machine using vector space decomposition** (1995), IEEE Transactions on Industry Applications. DOI: https://doi.org/10.1109/28.464525

Access: abstract record read (OpenAlex/Crossref); full text not read.

- **Claim:** Vector space decomposition (VSD) of a dual three-phase (two isolated neutrals) induction machine into three orthogonal subspaces separating torque-producing and non-torque harmonic currents; SVPWM limits 5th, 7th, 17th, 19th harmonics.
- **Method:** VSD analysis plus space-vector PWM; generalisable to any number of phases.
- **Machine / inverter:** Dual three-phase IM, VSI.
- **Power / voltage / speed numbers:** None (theory).
- **Relevance to SPB:** Mathematical backbone for SPB with isolated neutrals; the same decomposition underlies electronic pole changing (Osama1997modeling).
- **Limitations:** Two three-phase sets only; no traction ratings.
