# Magill2015dynamic

**A dynamic pole-phase modulation induction machine model (2015), IEMDC**. DOI: https://doi.org/10.1109/iemdc.2015.7409030

Access: abstract record read (Crossref/OpenAlex, DOI resolves); full text not read.

- **Claim:** Dynamic PPM model for machines with an arbitrary number of electrical inputs and pole configurations; decoupled energy-conversion subspaces per pole count via VSD; smooth 2/6-pole transition under FOC in simulation.
- **Method:** VSD-based model, FEA verification, simulation (Magill and Krein, UIUC).
- **Machine / inverter and numbers:** Simulation only.
- **Relevance to SPB:** Earliest general model that treats N independent electrical inputs; SPB modules are such inputs.
- **Limitations:** No hardware; IM.
