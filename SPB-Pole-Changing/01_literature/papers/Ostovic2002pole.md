# Ostovic2002pole

**Pole-changing permanent-magnet machines** (2002), IEEE Transactions on Industry Applications. DOI: https://doi.org/10.1109/tia.2002.805568

Access: abstract record read (OpenAlex/Crossref); full text not read.

- **Claim:** A PM memory motor can change its pole number as simply as a squirrel cage by re-magnetising low-coercivity magnets.
- **Method:** Principle of operation plus measurements.
- **Machine / inverter:** Memory-motor PM machine.
- **Power / voltage / speed numbers:** Measured performance in paper (not extracted).
- **Relevance to SPB:** Shows PM pole changing requires re-magnetising low-coercivity magnets, the exception to the fixed-PM-pole rule.
- **Limitations:** Needs magnetisation current pulses; small power.
