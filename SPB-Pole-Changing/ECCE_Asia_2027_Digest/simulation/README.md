# Simplified simulation

Run `run_simplified_screen.py` using the bundled Python interpreter. It uses the task-local `vendor/` plotting environment; no sibling research script is imported or executed. All output paths derive from the script location, so the working directory does not affect output location.

## What is computed
1. Direct instantaneous phase power for all 16 cells, using interleaved coil angles and two sinusoidal spatial orders.
2. Cell power minus the instantaneous cell mean, with checks of neutral sums and total stack power.
3. A periodic energy-buffer sizing estimate obtained by integrating the nominal-recharge power mismatch. Voltage is calculated from E=CV²/2. This is not a simulation of exact controlled series-cell dynamics.
4. A discrete coil-pitch sweep using the minimum absolute pitch factor of two orders. Unit distribution factor is assumed. It is not a full winding optimization.

Cases: A=m3 4/2 poles; B=m5 6/2 poles; C=m5 4/2 poles; E3 and E5=m3/m5 8/4 poles as algebraic controls. Total poles are twice the spatial order.

Parameters: N=16, nominal 75 V/cell, 2100 rpm, 0.2 s, 10 µs step, equal modal amplitudes and unity power factor. Per-phase RMS voltage=16 sqrt(3/m) V; current=200 sqrt(3/m) A. Both mean real cell power (9.6 kW) and summed squared RMS current (120000 A²) are held constant. This normalization does not establish equal copper loss unless winding resistance is equal. It is not a 300 kW motor operating point.

## Main results
- A: 9600 W cell cross-power amplitude at 105 Hz; 14.551 J energy amplitude; 27.230 mF nominal-recharge buffer requirement for a centered energy excursion inside 75 V +/-10%. The linearized estimate is 25.869 mF.
- B and C: ideal cross-power cancellation to floating-point precision; this does not imply zero total required capacitance.
- E3: the same power amplitude at 210 Hz gives 13.615 mF; this checks the inverse-frequency scaling. E5 cancels the ideal term.
- At short span limited to the high-pole full pitch: minimum pitch factors A=0.707, B=0.489, C=0.707. Unrestricted B reaches 1 only with a 180-degree mechanical coil span.

Energy integration error against the analytic sinusoidal amplitude: about 3.63e-6 relative. Script assertions verify the spatial rule against direct phase sums, the cross-term identity, neutral sums, total stack power and the energy integration tolerance.

## Outputs
`results/simplified_screen.json` is the numerical source of truth; `case_summary.csv` is a compact table; `traces.npz` retains numerical traces. PNG and editable SVG figures are in `../figures/`. `requirements_snapshot.json` records the task-local plotting package versions. Existing machine-simulation results are not relabeled as new results.

## Limits
No rotor, torque, PWM, saturation, magnetic loss, heat, end-winding resistance, device loss or balancing controller is simulated. A real series stack obeys C dVj/dt=Istack-Pj/Vj and can drift or become unstable without balancing. The present energy-buffer conversion must not be called a validated stack-voltage prediction. A case with negative calculated capacitor energy is flagged invalid; its minimum voltage is not reported as a physical zero. The current model is useful for screening and figure preparation, not final performance claims.
